🍕 KulaNova - Food Delivery Website

🎯 About The Project

KulaNova is a modern, responsive food delivery website built with React and Flask. It allows customers to browse delicious meals, add items to a persistent shopping cart, and place orders for delivery.

🎨 Design Theme & Colors

The website features a warm, food-friendly color palette that stimulates appetite while maintaining a clean, professional look:

Primary Colors:

· nova-orange #FF6B35 - Main brand color (energetic, appetite-stimulating)
· nova-red #FF2E00 - Accent color for hover states (passion, excitement)
· nova-yellow #FFA726 - Secondary accent (warmth, happiness)
· nova-gray #37474F - Text and neutral elements (professional, clean)
· nova-light #FFF3E0 - Backgrounds (soft, welcoming)

Typography:

· Headings: Poppins (Bold, modern)
· Body Text: Open Sans (Readable, clean)

✨ Features

· 🛍️ Interactive Shopping - Browse meals, view details, add to cart
· 💾 Persistent Cart - Items saved in browser memory (never lose your order!)
· 📱 Fully Responsive - Works perfectly on phones, tablets, and desktops
· 🔍 Product Details Modal - Click "Details" to see full meal information
· 📞 Contact Form - Send messages directly to the restaurant
· ⚡ Fast Performance - Built with Vite for lightning-fast loading
· 🎨 Beautiful Animations - Smooth transitions and interactive elements

🛠️ Tech Stack

Frontend:

· React - UI components and state management
· Tailwind CSS - Styling and responsive design
· React Router - Page navigation
· Context API - Global cart state management
· LocalStorage - Persistent cart storage

Backend:

· Python Flask - REST API server
· SQLite - Database (lightweight, file-based)
· SQLAlchemy - Database ORM

🚀 Getting Started

1. Backend Setup:
   ```bash
   cd backend
   python app.py
   ```
2. Frontend Setup:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
3. Open Browser: http://localhost:5173

📱 Pages

1. 🏠 Home - Welcome page with hero section, features, and testimonials
2. 🛍️ Shop - Full menu with filtering, cart functionality, and product details
3. 📞 Contact - Contact form, business info, and FAQ section

🎮 User Flow

1. Browse delicious meals in the Shop
2. Click Details to learn more about any item
3. Add to Cart with one click
4. View Cart to review your order
5. Checkout (simulated for demo)
6. Your cart persists even after closing the browser!
