How These Work Together:

Product Card Example:

```html
<div class="card hover-lift">
  <h3 class="line-clamp-1">Super Deluxe Mega Burger</h3>
  <p class="line-clamp-2">This burger has everything you could ever want...</p>
</div>
```

What happens:

1. Card has shadow (from Tailwind)
2. Hovers and lifts up (from hover-lift)
3. Title shows 1 line only (from line-clamp-1)
4. Description shows 2 lines only (from line-clamp-2)

The Magic of CSS Animations:

@keyframes fadeIn = Choreography

```css
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
```

"Step 1: Be invisible and lower. Step 2: Be visible and normal position."

.fade-in = Dancer Following Choreography

```css
.fade-in {
  animation: fadeIn 0.5s ease-out;
}
```

"Do the fadeIn dance for 0.5 seconds, starting fast and ending slow."

Technical Magic Explained Simply:

transform: translateY(-5px)

"Move this element 5 pixels UP on the Y-axis (vertical)"

· Positive numbers = Move DOWN
· Negative numbers = Move UP
· translateX would move left/right

transition: transform 0.2s ease

"When transform changes, do it over 0.2 seconds with easing"

· ease = Start fast, slow down at end (like a car stopping)
· linear = Same speed entire time (like a train)
· ease-in = Start slow, end fast (like a rocket)
· ease-out = Start fast, end slow (like a ball rolling to stop)

-webkit-line-clamp: 2

"WebKit browsers (Chrome, Safari), clamp to 2 lines!"

· -webkit- = For WebKit browsers
· Other browsers have their own prefixes
· Modern browsers understand this now
