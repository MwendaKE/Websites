## SomaNova

SomaNova is a simple and modern second-hand book marketplace.
It helps readers discover affordable, pre-owned books through a clean and easy-to-use interface.

---

### Theme & Colors

Navy Blue – #1e3a8a
Gold/Yellow – #fbbf24
White – #ffffff
Light Gray – #f3f4f6

These colors create a warm, elegant, and trustworthy reading atmosphere.

---

### Tech Stack

Frontend: React, React Router, Vite, CSS
Backend: Flask, SQLAlchemy, SQLite
API Communication: Fetch API
Environment: Termux / NodeJS / Python

---

### Features

Clean and modern UI
Homepage with welcome message
Book collections grouped by categories
Book detail page
About and Contact pages
Default image for books without images
Simple and fast backend API
